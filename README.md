# Jesús Navas Guerrero · portfolio

Web personal estática, organizada como seis niveles. El diseño usa una paleta cálida de tonos carne y marrón, con el texto como elemento principal.

GitHub Pages publica directamente la carpeta `docs/` de la rama `main`. No hace falta instalar dependencias ni ejecutar un build.

Para verla en local:

```sh
python3 -m http.server 8765 --directory docs
```

Los textos de cada nivel están en `docs/app.js`. El contenido profesional inicial procede del CV de noviembre de 2025; conviene revisar los cargos abiertos antes de actualizar su estado actual.
