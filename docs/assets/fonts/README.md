# Portfolio fonts

The portfolio uses Inter for body text and navigation, and Libre Baskerville for
display headings and the personal wordmark. Both fonts are served locally, with
their SIL Open Font License files included in this directory.

These fonts provide an editorial style inspired by McKinsey's visual identity.
They are not McKinsey's Bower typeface. The reference for that identity is the
original design team's case study: https://www.wolffolins.com/work/mckinsey.
